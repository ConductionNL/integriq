# Screens

The flow screens are one set (decision 379, 5 Nov 2026): the canonical boards live under OpenRegister, and an app's flow board is a variant that imports the shared parts with the app's own example flow, step types and wording.

- IqFlow: the integriq flow editor with webhook, mapping, split, AI agent, code, approval, subflow and error path steps, and the runs of the flow; variant of the canonical set, imports OrFlowKop, OrFlowPalet, OrFlowCanvas, OrFlowStap, OrFlowRuns https://identity.conduction.nl/screens/board?id=integriq/IqFlow
- openregister/OrFlow: the canonical editor this variant follows https://identity.conduction.nl/screens/board?id=openregister/OrFlow
